# Security policy

## Supported version

Only the latest commit on `main` is supported. This repository is an educational database project and is not operated as a hosted commerce service.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability or exposed credential. Use the repository's private security-advisory feature on GitHub.

Include the affected file or route, the impact, and minimal reproduction steps. Do not include live credentials, personal data, or unrelated database records.
